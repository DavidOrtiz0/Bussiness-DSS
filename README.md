# 📊 Sistema DSS - Análisis de Datos Yelp

## 📌 Descripción

Este proyecto corresponde a un **Sistema de Soporte a Decisiones (DSS)** diseñado para el análisis de datos del **Yelp Open Dataset**, con el objetivo de generar información útil para la toma de decisiones en contextos de mercado.

La aplicación permite explorar datos, realizar análisis estratégicos y generar reportes, integrando diferentes tecnologías modernas dentro de una arquitectura desacoplada.

## 🏗️ Arquitectura

- Cliente / Aplicación / Base de datos


Se estructura en:

- 📊 **Capa de datos**: Gestión y almacenamiento de información.
- ⚙️ **Capa de lógica**: Procesamiento, validación y análisis.

## 📦 Instalación

```bash
# Clonar el repositorio
git clone https://github.com/DavidOrtiz0/Bussiness-DSS.git

# Ingresar al proyecto
cd Bussiness-DSS

# Instalar dependencias
npm install

El sistema sigue una arquitectura basada en separación de responsabilidades, permitiendo una interacción eficiente entre los distintos componentes.
```

## ▶️ Ejecución

```bash
# Ejecutar el proyecto en entorno de desarrollo
npm run dev
```
